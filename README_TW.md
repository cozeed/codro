## Codro 目前處於 Beta 階段 ⚠️

目前 Codro 處於 beta 階段，建議在有資料備份的情況下使用。

## 功能特性

- 🖥️ **本地優先（Local-first）：** 所有資料儲存在本地，支援離線使用，並可在不同裝置之間同步。
- 🎨 **應用場景：** 白板與自由繪製圖表；流程圖、時序圖、架構圖、示意圖、心智圖等；以及結構化筆記與文件編輯。
- 🤖 **AI Chat：** 支援透過聊天與 AI 助手互動。支援 OpenAI、Anthropic、Google、DeepSeek 等多種大模型。
- 📊 **圖表類型：** 支援 Excalidraw、tldraw、draw.io、Mindmap、Note 等圖表類型。
- ⚡ **輕量級：** 基於 Tauri，安裝體積小於 20MB，效能更佳。
- 🌍 **多語言支援：** 支援英文、日文、簡體中文、繁體中文等多種語言。
- 💻 **跨平台支援：** 支援 Web、Windows、macOS、Linux 等多個平台。
