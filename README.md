## Codro is in Beta ⚠️

Codro is currently in the beta phase. It is recommended to use it with data backups.

## Features

- 🖥️ **Local-first:** All data is stored locally, enabling full offline usage, with optional sync across devices.
- 🎨 **Use Cases:** Whiteboard and freeform drawing; flowcharts, sequence diagrams, architecture diagrams, illustrations, mind maps; as well as structured notes and document editing.
- 🤖 **AI Chat:** Interact with AI assistants via chat. Supports models from OpenAI, Anthropic, Google, and DeepSeek.
- 📊 **Diagram Types:** Supports Excalidraw, tldraw, draw.io, Mindmap, Note, and more.
- ⚡ **Lightweight:** Built with Tauri, with an installation size under 20MB and improved performance.
- 🌍 **Multilingual Support:** Supports English, Japanese, Simplified Chinese, and Traditional Chinese.
- 💻 **Cross-Platform:** Available on Web, Windows, macOS, and Linux.

## How to Contribute

Codro is still in its early stages and may have some rough experiences or bugs. All interested users or those encountering issues are welcome to submit [issues](https://github.com/cozeed/codro/issues/new) or [PRs](https://github.com/cozeed/codro/compare) to contribute to this project.
